# 📝 Flask Blogging App

A simple blogging platform built with Flask that allows users to create, view, and delete blog posts. This was one of my early backend projects where I explored routing, templates, forms, and basic CRUD operations using Flask and SQLite.

---

## 🚀 Features

- Create new blog posts
- View all published posts
- Delete existing posts
- Update an existing post
- Search for posts
- Like and comment on posts
- Lightweight UI using HTML 
- SQLite database integration

---

## 🛠️ Tech Stack

- **Flask** – Python web framework
- **SQLite** – Lightweight relational database
- **HTML/CSS** – Frontend templating
